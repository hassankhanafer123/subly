# Subly — OpenDesign brief

Paste **PROMPT.md** into OpenDesign (desktop app or CLI). It references the
other files in this folder. When OpenDesign gives you HTML/React mockups,
drop the exported files (or screenshots) back to me and I port the exact
visual design into the React Native app.

## Files
- `PROMPT.md`   — the prompt to paste into OpenDesign
- `SCREENS.md`  — every screen, its content, and layout intent
- `BRAND.md`    — non-negotiable rules (general audience, palette, type)
- `airbnb-DESIGN.md` — the Airbnb design-system token spec to load

## Recommended OpenDesign setup
1. Design system: **airbnb** (load `airbnb-DESIGN.md`, or pick "airbnb" from
   its built-in design systems).
2. Template: **mobile-app** (iPhone 15 Pro frame) for the 4 tabs,
   **mobile-onboarding** for the welcome flow.
3. Generate one screen at a time; iterate in OpenDesign until it's right.
4. Export → hand back to me.
